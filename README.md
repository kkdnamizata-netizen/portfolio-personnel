# Portfolio personnel – Kamagate Djamila

## 1. Présentation du projet

Ce projet consiste à réaliser un portfolio personnel sous forme de site web One Page.

Il permet de présenter mon parcours académique, mes compétences informatiques, mes réalisations, mon CV et mes informations de contact.

Ce portfolio a également pour objectif de présenter mon profil dans le cadre de ma recherche de stage.

## 2. Technologies utilisées

- **HTML5** : structure et organisation du site.
- **CSS3** : mise en forme et design.
- **Tailwind CSS** : création de l'interface.
- **jQuery** : interactions et animations.
- **JavaScript** : fonctionnalités interactives.

## 3. Fonctionnalités du portfolio

Le site comprend les sections suivantes :

- Accueil
- À propos
- Compétences
- Formation
- Réalisations (projets pratiques)
- CV téléchargeable au format PDF
- Contact
- Présentation vidéo

## 6. Lancement du projet

Le portfolio est un site web statique.

Pour le consulter :

1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Lancer un serveur local depuis le terminal avec la commande :

bash
python -m http.server 8000


3. Ouvrir le navigateur à l'adresse :

text
http://localhost:8000

## 8. Formulaire de contact

Le site possède un formulaire de contact comprenant les champs suivants :

- Nom
- Adresse e-mail
- Message

Le formulaire utilise jQuery pour empêcher le rechargement de la page et afficher les données saisies dans la console du navigateur.

L'envoi réel des messages nécessite une connexion à un service de traitement de formulaires.
